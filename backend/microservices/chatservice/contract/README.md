# chatservice API contract

`openapi.yaml` is the OpenAPI 3.1 spec for chatservice, generated by
[springdoc-openapi](https://springdoc.org/) from the annotated controllers —
not hand-written. It's a snapshot of the real `/v3/api-docs.yaml` output, so
it can drift if the code changes without regenerating it.

Lives here, next to the service that generates it, rather than in a shared
root-level `contracts/` folder — it's versioned with chatservice's own
commits, and every future service gets its own `contract/` the same way. See
`AGENTS.md`'s "Contracts (per-service)" section for the convention.

## Regenerate

```bash
# 1. Postgres runs persistently in Docker as `chatplatform-postgres`
#    (chatuser/chatpass@localhost:5432/postgres, migrations already applied) - it
#    should already be up; no need to start/stop it per regen.
# 2. From backend/microservices/chatservice:
./mvnw spring-boot:run
# 3. In another shell, from that same directory:
curl http://localhost:8080/v3/api-docs.yaml -o contract/openapi.yaml
```

Swagger UI is also available at `http://localhost:8080/swagger-ui.html`, and
the [BootUI](https://www.julien-dubois.com/boot-ui/) dev console at
`http://localhost:8080/bootui`, while the app is running.
