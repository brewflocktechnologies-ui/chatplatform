<Subtitle>Pure presentational layout template component for the chat widget surface.</Subtitle>

`cw-widget-layout` is the Template layer component in the Atomic Design hierarchy. It accepts pure configuration properties and lays out the floating trigger (bubble/chatbar), proactive greet window, and main chat panel without subscribing to any store.
