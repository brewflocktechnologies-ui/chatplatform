<Title>Zotly Chat Widget — Design System</Title>

<Subtitle>An atomic design system for the chat widget, built with Lit web components.</Subtitle>

This Storybook documents the widget's component library, organised using **atomic design**:
a strict 5-layer hierarchy from tiny atoms up to the live page container.

<Heading as="h2">The 5-layer hierarchy</Heading>

- **Atoms** — the smallest building blocks (icon, badge, status dot, typing dots…). No business logic.
- **Molecules** — groups of atoms that form a meaningful UI unit (avatar, composer, message bubble, chat footer, emoji picker, attach menu, chat menu…).
- **Organisms** — sections composed of molecules (chat panel, header, floating trigger, greet window…).
- **Templates** — pure layout skeletons (`cw-widget-layout`). Structure only, props in, zero store dependency.
- **Pages** — the live smart container (`cw-widget-root`). Handles store subscriptions, event bus, config merging, and renders the template.

<Heading as="h2">Guiding rules</Heading>

1. **Templates are structural** — `cw-widget-layout` accepts pure props and lays out triggers, greet window, and panel.
2. **Pages wire live state** — `cw-widget-root` owns store subscriptions, event bus, and config merging.
3. **Data flows down** — properties are passed down the 5-layer hierarchy.
4. **Events flow up** — leaves emit composed `cw:*` events up to the root page container.
